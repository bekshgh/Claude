# Brick Engineers — 15 s promo (1920×1080, 60 fps)

Final video: [`../output/brick_engineers_promo_1920x1080_60fps.mp4`](../output/brick_engineers_promo_1920x1080_60fps.mp4)

A premium motion-design promo built from the supplied green-screen character/prop sheet
(`reference/character_prop_sheet.png`). Everything is rendered procedurally: real 3D glossy
studded bricks in three.js, the five engineers and eight props taken pixel-for-pixel from the
sheet (so faces, outfits and proportions stay identical in every shot), and a fully synthesised
120 BPM soundtrack with SFX locked to the animation events.

Palette: golden amber `#D8901C`, burnt orange `#C0601A`, deep rust `#A84018`, white, bright
yellow. No text, letters or logos anywhere in frame.

## Audio

`audio/soundtrack.wav` (48 kHz stereo) is generated by `tools/audio.py` from the event list
exported by the renderer (`audio/events.json`): four-on-the-floor kick, claps, 16th hats,
sidechained rhythmic bass, bright plucks and stabs in D major, plus a plastic click on every
brick snap (dense clusters are thinned), whooshes on every wipe/whip, a riser from 12.5 s, a warm
FM-bell chime and pad swell at the bulb switch-on (13.5 s) and a bright final stinger (14.5 s)
ringing out to 15 s. Mastered with a look-ahead limiter to −1 dBFS.

## How it was made / how to re-render

```bash
cd promo
npm install                                 # three.js
# 1) assets (already committed in assets/): key, upscale, rig
python3 tools/extract.py reference/character_prop_sheet.png sprites_raw
python3 tools/esrgan_onnx.py RealESRGAN_x4plus.pth x4plus.onnx   # weights from the Real-ESRGAN releases
python3 tools/upscale.py x4plus.onnx sprites_raw sprites_2x eng1 eng2 ...
python3 tools/rig.py sprites_2x assets
# 2) frames (headless Chromium + SwiftShader WebGL2), lossless 1 s chunks
node render.js --frames 0:900 --workers 3 --chunk 60 --out frames/final
# 3) soundtrack synced to the animation events
node render.js --events audio/events.json
python3 tools/audio.py audio/events.json audio/soundtrack.wav
# 4) delivery encode (H.264 High, CRF 14, BT.709, AAC 320k)
tools/encode.sh frames/final audio/soundtrack.wav ../output/brick_engineers_promo_1920x1080_60fps.mp4
```

- `tools/extract.py` — chroma key with projection unmixing against locally propagated
  foreground/background colours (keeps the dark-green circuit boards, removes spill and the
  shadowed green pockets between limbs).
- `tools/upscale.py` + `tools/esrgan_onnx.py` — Real-ESRGAN x4plus converted to ONNX without
  PyTorch, run with onnxruntime; sprites are kept at 2× for crisp close-ups.
- `tools/rig.py` — cuts each engineer into body/head/arm layers with pivots (arms holding
  objects in front of the torso stay fixed), rebuilds the turbine rotor from its own blade so it
  can spin, splits the robot arm into base/arm/gripper, and rectifies the solar panel and laptop
  faces into textures for real 3D props.
- `web/src` — three.js scene code: `bricks.js` (instanced studded bricks, clearcoat ABS
  material), `puppet.js` (layered billboard puppets with depth pre-pass, rim light,
  silhouettes), `post.js` (half-res bokeh DOF, bloom chain, god rays, whip/zoom blur, grade),
  `transitions.js` (brick-mosaic wipes), `shots/*.js` (one file per timeline segment).
- Every animated value is a pure function of time, so frames render deterministically in any
  order and any chunk can be re-rendered on its own.
